Change and review details

The extractor no longer creates or backfills availability metadata. Aggregation reads FTD source rows, their stored period, the global distinct period list, and at most one existing ZIP cache timestamp. The table registry, bootstrap DDL, and quality-script source requirement no longer name sec_ftd_vintages.

The correctness reviewer found one partial-universe bug, which was fixed and independently re-reviewed with no remaining issue. The simplicity reviewer proposed removing a day-15-only regression, but that distinct test failed against the old fallback and protects the reported defect.

Limits and operational boundary

The historical 15-day clock is an estimate, not verified SEC first-publication provenance. The physical vintage table may remain in PostgreSQL but no product path uses it. No database table was dropped; no saved cube rows, ZIP cache, aggregate fingerprint baseline, or user data were changed. This worktree has not been committed, pushed, or opened as a PR.
